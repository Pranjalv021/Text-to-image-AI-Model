# Report Outline - Text-to-Image Generation using Hugging Face Models

## 1. Abstract
A system that converts a text description into an image using pre-trained latent
diffusion models from Hugging Face, with an interactive interface, dataset-driven
prompts and automatic quality evaluation using CLIP.

## 2. Objectives
1. Use free pre-trained generative models and datasets from Hugging Face.
2. Build an easy-to-run application (local web UI + command line).
3. Evaluate image-text alignment and compare two models (speed vs quality).

## 3. Technologies
Python, PyTorch, Hugging Face `diffusers`, `transformers`, `datasets`, Gradio, CLIP.

## 4. System Architecture
    Prompt (typed or from HF dataset)
            |
    Text encoder -> embeddings
            |
    U-Net denoiser (latent space, few steps)  <- random noise (seed)
            |
    VAE decoder -> image  --> saved to outputs/
            |
    CLIP: score(image, prompt)  and  similarity(real image, generated image)

## 5. Methodology
* **Latent diffusion:** an image is generated by starting from random noise in a
  compressed (latent) space and removing noise step by step, guided by the text
  embedding; a VAE then decodes the latent into pixels.
* **SD-Turbo:** a distilled Stable Diffusion model that produces an image in 1-4
  steps (adversarial diffusion distillation), so it is fast enough for a laptop CPU.
* **Tiny-SD:** a smaller, knowledge-distilled Stable Diffusion 1.5 (fewer parameters,
  smaller download, more steps needed).
* **Guidance scale:** how strongly the image follows the prompt (turbo models use 0).
* **Seed:** makes results reproducible.
* **CLIP score:** 100 x max(cosine(image embedding, text embedding), 0). Higher means
  the image matches the text better. Real-vs-AI similarity is the cosine of CLIP
  image embeddings.

## 6. Datasets
* Gustavosta/Stable-Diffusion-Prompts - about 80k text prompts (source of test prompts).
* lambdalabs/pokemon-blip-captions - real images with captions (real-vs-AI comparison).
Both are loaded programmatically with `datasets.load_dataset`.

## 9. Limitations
Small CLIP-based evaluation (CLIP is an imperfect proxy for human judgement); CPU
generation is slow; models can reproduce biases of their training data; quality
varies with prompt wording.

## 10. Future Work
Fine-tune on a custom dataset (LoRA), add image-to-image or inpainting, add human
rating, deploy on Hugging Face Spaces.

## 12. Likely viva questions
1. What is a diffusion model? - It learns to reverse a gradual noising process.
2. Why "latent" diffusion? - Works in a compressed space, so it is much cheaper.
3. Why is SD-Turbo faster? - Distillation lets it generate in 1-4 steps.
4. What is guidance scale? - Strength of prompt-following (classifier-free guidance).
5. What does the seed do? - Fixes the starting noise, giving reproducible images.
6. What is CLIP and how do you use it? - Joint image-text embedding model; cosine
   similarity measures prompt-image match.
7. Why stream the dataset? - Avoid downloading the whole dataset; only needed samples.
8. How would you improve the model for your own domain? - Fine-tune / LoRA.
